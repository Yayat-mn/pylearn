1.1 Sejarah Python

Python dikembangkan oleh Guido van Rossum, seorang programmer asal Belanda. Pengembangan Python dimulai pada akhir 1980-an di CWI (Centrum Wiskunde & Informatica), sebuah pusat penelitian matematika dan ilmu komputer di Belanda.

Versi pertama Python, yaitu Python 0.9.0, dirilis pada 1991. Sejak saat itu Python terus berkembang menjadi salah satu bahasa pemrograman yang paling banyak digunakan di dunia.

Nama Python tidak diambil dari jenis ular. Guido memilih nama tersebut karena terinspirasi grup komedi Inggris Monty Python's Flying Circus, sebuah pertunjukan yang ia sukai.

Python 2.0 dirilis pada 2000 dan Python 3.0 pada 2008. Python 3 menjadi versi yang digunakan hingga sekarang. Pada 2001, dibentuk Python Software Foundation (PSF), organisasi nirlaba yang mengelola dan mempromosikan pengembangan Python.

1.2 Pengenalan, Kegunaan, dan Fitur Python

Python adalah bahasa pemrograman tingkat tinggi yang bersifat general-purpose, artinya dapat digunakan untuk berbagai jenis pekerjaan, bukan hanya satu bidang tertentu. Python juga umumnya dijalankan menggunakan interpreter dan mendukung beberapa gaya pemrograman, seperti prosedural, berorientasi objek, dan fungsional.

Salah satu alasan Python populer adalah sintaksnya yang relatif mudah dibaca. Kode Python lebih mirip bahasa manusia dibandingkan banyak bahasa pemrograman lain, sehingga cocok untuk pemula yang baru belajar pemrograman.

Kegunaan Python

  • Pengembangan web dengan framework seperti Django dan Flask.
  • Analisis data menggunakan pustaka seperti NumPy dan pandas.
  • Kecerdasan buatan dan machine learning dengan TensorFlow atau PyTorch.
  • Otomasi pekerjaan, misalnya mengolah berkas, mengambil data dari internet, atau menjalankan tugas berulang.
  • Pendidikan, karena sintaksnya cocok untuk mempelajari konsep dasar pemrograman.

Fitur penting Python

  • Mudah dipelajari dan mudah dibaca.
  • Lintas platform: dapat berjalan di Windows, Linux, dan macOS.
  • Open source dan memiliki komunitas pengguna yang besar.
  • Dilengkapi banyak pustaka bawaan (batteries included) serta pustaka pihak ketiga.
  • Mendukung pengelolaan memori otomatis sehingga programmer tidak perlu mengatur memori secara manual. 
print("Halo, Python!")

Kode di atas menggunakan fungsi print() untuk menampilkan teks ke layar. Kita akan mempelajarinya lebih lanjut pada subbab 1.6.

1.3 Kelebihan, Kekurangan, dan Perbandingan Hello World

Setiap bahasa pemrograman memiliki kelebihan dan kekurangan. Memahami keduanya membantu kita memilih bahasa yang sesuai dengan kebutuhan program.

Kelebihan Python

  • Mudah dipelajari, terutama bagi pemula.
  • Sintaks ringkas sehingga program lebih cepat ditulis.
  • Dapat berjalan di berbagai sistem operasi.
  • Memiliki ekosistem pustaka yang sangat luas.
  • Open source dan didukung komunitas yang besar.
  • Cocok untuk pengembangan cepat, prototipe, dan eksperimen.

Kekurangan Python

  • Pada beberapa kasus, eksekusinya lebih lambat dibanding bahasa yang dikompilasi menjadi kode mesin, seperti C atau C++.
  • Konsumsi memori relatif lebih besar untuk sebagian program.
  • Karena bertipe dinamis, beberapa kesalahan baru terdeteksi saat program dijalankan.
  • Tidak selalu menjadi pilihan utama untuk pemrograman tingkat rendah atau aplikasi yang sangat bergantung pada performa.

Perbandingan Hello World

Program Hello World biasanya menjadi program pertama saat mempelajari bahasa pemrograman. Perhatikan perbedaan panjang kode pada tiga bahasa berikut.

C++

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

Java

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Python

print("Hello, World!")

Python tidak membutuhkan deklarasi kelas atau fungsi main untuk program sederhana. Meskipun ringkas, Python tetap menuntut penulisan yang konsisten, terutama indentasi pada blok kode.

1.4 Cara Kerja Interpreter dan Compiler

Komputer tidak langsung memahami kode yang ditulis dalam bahasa pemrograman. Kode tersebut perlu diterjemahkan terlebih dahulu. Ada dua pendekatan utama yang biasa digunakan: compiler dan interpreter.

  • Compiler menerjemahkan seluruh kode sumber menjadi kode mesin atau berkas yang dapat dijalankan sebelum program berjalan. Contoh bahasa yang umum memakai compiler adalah C dan C++.
  • Interpreter membaca dan menjalankan kode secara bertahap. Program tidak harus diubah menjadi berkas executable terlebih dahulu. Contoh bahasa yang umum memakai interpreter adalah Python dan JavaScript.

Python sebenarnya terlebih dahulu mengubah kode sumber menjadi bytecode, lalu bytecode tersebut dijalankan oleh Python Virtual Machine (PVM). Karena itu Python sering disebut sebagai bahasa yang diinterpretasikan.

Interpreter biasanya lebih memudahkan proses pengujian dan debugging karena kode dapat langsung dijalankan. Namun, program yang dikompilasi menjadi kode mesin umumnya memiliki performa lebih tinggi.

1.5 Instalasi Python di Windows

Untuk menjalankan Python secara lokal di komputer Windows, Python perlu diinstal terlebih dahulu. Langkah umumnya adalah sebagai berikut.

  1. Buka situs resmi python.org/downloads.
  2. Unduh installer Python untuk Windows.
  3. Jalankan installer, lalu centang opsi Add python.exe to PATH.
  4. Klik Install Now dan tunggu hingga proses instalasi selesai.
  5. Buka Command Prompt, lalu jalankan perintah berikut untuk memeriksa instalasi. 
python --version

Jika instalasi berhasil, Command Prompt akan menampilkan versi Python yang terpasang, misalnya Python 3.x. Jika perintah python tidak dikenali, coba gunakan py --version atau ulangi instalasi dengan opsi PATH yang benar.

Python juga menyediakan IDLE, yaitu editor sederhana yang dapat digunakan untuk mencoba mode interaktif dan menulis skrip.

Catatan: PYLearn berjalan di browser dan sudah menyediakan editor Python, sehingga kamu tidak perlu menginstal Python untuk mengerjakan latihan di situs ini. Instalasi lokal berguna jika ingin berlatih di luar PYLearn.

1.6 Mode Interaktif, Mode Skrip, print(), dan input()

Python dapat dijalankan dengan dua cara utama: mode interaktif dan mode skrip. Keduanya memiliki kegunaan yang berbeda.

Mode interaktif

Pada mode interaktif, kita mengetik instruksi satu per satu. Python langsung menjalankan instruksi tersebut dan menampilkan hasilnya. Mode ini biasanya ditandai dengan prompt >>>. 

>>> 2 + 3
5
>>> print("Halo")
Halo

Mode interaktif cocok untuk mencoba potongan kode kecil. Namun, mode ini kurang praktis untuk program panjang karena instruksi tidak disimpan dalam satu berkas.

Mode skrip

Pada mode skrip, kode ditulis dalam sebuah berkas, misalnya halo.py, lalu dijalankan sekaligus. Seluruh instruksi dalam berkas dieksekusi dari atas ke bawah. 

# halo.py
print("Halo, PYLearn!")
print("Saya sedang belajar Python.")

Berkas tersebut dapat dijalankan melalui Command Prompt dengan perintah python halo.py. Mode skrip cocok untuk program yang lebih lengkap dan perlu disimpan.

Di PYLearn, editor kode menjalankan program dalam mode skrip. Klik tombol Jalankan atau Periksa Output untuk mengeksekusi seluruh kode di editor. PYLearn belum menyediakan prompt interaktif; untuk mencoba mode interaktif, gunakan IDLE atau terminal Python di komputer.

print() dan input()

Fungsi print() digunakan untuk menampilkan keluaran ke layar. Teks yang ditampilkan harus berupa string, yaitu teks yang diapit tanda kutip tunggal atau ganda. 

print("Halo, Python!")
print("Belajar", "Python")

Baris pertama menampilkan Halo, Python!, sedangkan baris kedua menampilkan Belajar Python karena beberapa argumen dipisahkan dengan spasi.

Fungsi input() digunakan untuk menerima masukan dari pengguna. Hasil input() selalu berupa string. 

nama = input("Siapa namamu? ")
print("Halo, " + nama)

Pada contoh di atas, hasil input() disimpan ke variabel nama. Variabel akan dibahas lebih lanjut pada Modul 2.

Catatan PYLearn: input() belum didukung di editor PYLearn. Untuk mencoba contoh input(), jalankan kode tersebut di IDLE atau terminal Python. Latihan di PYLearn akan memakai print() agar dapat dinilai secara otomatis.

Program pertama

Perhatikan contoh program mode skrip berikut, lalu jalankan melalui editor PYLearn. 

print("Halo, PYLearn!")
print("Saya sedang belajar Python.")

Hasil yang diharapkan

Halo, PYLearn!
Saya sedang belajar Python.
Python itu menyenangkan!

Ubah salah satu teks di dalam print(), lalu jalankan kembali untuk melihat perubahannya. Perhatikan bahwa setiap print() berada di baris baru.

  • Python dikembangkan oleh Guido van Rossum dan pertama kali dirilis pada 1991.

  • Kelebihan Python antara lain sintaksnya sederhana dan pustakanya luas; kekurangannya antara lain lebih lambat pada beberapa kasus dan menggunakan memori relatif besar.
  • Compiler menerjemahkan seluruh kode sebelum dijalankan, sedangkan interpreter menjalankan kode secara bertahap.
  • Instalasi Python di Windows perlu mencentang opsi Add python.exe to PATH agar perintah python dapat digunakan.
  • Mode interaktif menjalankan instruksi satu per satu, sedangkan mode skrip menjalankan seluruh isi berkas. PYLearn menggunakan mode skrip.

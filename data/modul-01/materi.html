1.1 Apa Itu Python?

Python adalah bahasa pemrograman tingkat tinggi yang digunakan untuk memberikan instruksi kepada komputer. Python dikenal memiliki sintaks yang relatif mudah dibaca sehingga sering digunakan untuk mempelajari konsep dasar pemrograman.

Program Python tersusun atas instruksi yang dieksekusi oleh interpreter Python. Dalam PYLearn, kamu dapat mencoba instruksi tersebut langsung melalui editor kode interaktif.

1.2 Kegunaan Python

Python digunakan dalam berbagai bidang, misalnya pengembangan aplikasi web, analisis data, otomasi pekerjaan berulang, dan kecerdasan buatan. Pada pembelajaran dasar, Python dapat membantu mahasiswa memahami variabel, operator, percabangan, perulangan, dan fungsi.

1.3 Sintaks Dasar Python

Sintaks adalah aturan penulisan instruksi dalam bahasa pemrograman. Salah satu instruksi sederhana dalam Python adalah print(), yang digunakan untuk menampilkan keluaran.

print("Halo, PYLearn!")

Teks yang diapit tanda kutip merupakan string. Python membedakan huruf besar dan kecil, sehingga print tidak sama dengan Print.

Python juga menggunakan indentasi untuk menandai blok kode, misalnya pada percabangan dan perulangan. Konsep tersebut akan dipelajari lebih lanjut pada modul berikutnya.

1.4 Program Python Pertama

Perhatikan contoh berikut, kemudian jalankan melalui editor Python yang disediakan PYLearn.

print("Halo, PYLearn!")
print("Saya sedang belajar Python.")

Hasil yang diharapkan

Halo, PYLearn!
Saya sedang belajar Python.

Coba Sendiri

Ubah pesan pada fungsi print() agar menampilkan namamu dan satu alasan mengapa kamu ingin belajar Python. Jalankan kembali kode dan amati hasilnya melalui tahap Latihan.

Rangkuman

Python merupakan bahasa pemrograman yang dapat digunakan untuk berbagai kebutuhan. Instruksi print() dapat digunakan untuk menampilkan keluaran, dan sintaks yang benar diperlukan agar program dapat dijalankan.

7.1 Manfaat Fungsi dan Dasar Pembuatannya

Fungsi adalah blok kode bernama yang dirancang untuk melakukan tugas tertentu. Setelah dibuat, fungsi dapat dipanggil berkali-kali tanpa perlu menulis ulang isi kodenya. Fungsi membantu kita menyusun program menjadi bagian-bagian yang lebih kecil dan mudah dipahami.

Manfaat penggunaan fungsi

  • Menghindari pengulangan kode. Kode yang sama cukup ditulis sekali di dalam fungsi, lalu dipanggil saat dibutuhkan.
  • Membuat program lebih terstruktur. Setiap fungsi mempunyai tugas yang jelas sehingga program lebih mudah dibaca.
  • Memudahkan perbaikan. Jika ada kesalahan, kita cukup memperbaiki satu tempat, bukan menyalin perbaikan ke banyak baris.
  • Dapat digunakan ulang. Fungsi yang sama dapat dipanggil dengan nilai berbeda pada bagian program yang lain.

Membuat dan memanggil fungsi

Fungsi dibuat dengan kata kunci def, diikuti nama fungsi, tanda kurung, dan tanda titik dua. Isi fungsi ditulis dengan indentasi. Perhatikan bentuk dasarnya berikut. 

def tampilkan_judul():
    print("=== DAFTAR NILAI ===")
    print("Mata kuliah: Python")

tampilkan_judul()

Baris def tampilkan_judul(): hanya mendefinisikan fungsi. Fungsi baru berjalan ketika dipanggil dengan menuliskan namanya diikuti tanda kurung, yaitu tampilkan_judul(). 

def sapa():
    print("Halo, selamat datang di PYLearn!")
    print("Semoga belajarmu menyenangkan.")

sapa()
sapa()

Fungsi sapa() dipanggil dua kali sehingga kedua baris di dalamnya dijalankan dua kali. Inilah keuntungan utama fungsi: tulis sekali, panggil sebanyak yang diperlukan.

Nama fungsi sebaiknya ditulis dengan huruf kecil dan menggunakan garis bawah jika terdiri atas beberapa kata, misalnya hitung_total() atau tampilkan_menu(). Nama fungsi tidak boleh mengandung spasi dan tidak boleh diawali angka. Fungsi juga harus didefinisikan sebelum dipanggil.

7.2 Fungsi dengan Parameter

Parameter adalah variabel yang ditulis di dalam tanda kurung pada definisi fungsi. Nilai yang diberikan saat fungsi dipanggil disebut argumen. Dengan parameter, fungsi dapat mengolah data yang berbeda setiap kali dipanggil.

Fungsi dengan satu parameter

def sapa(nama):
    print("Halo,", nama)

sapa("Andi")
sapa("Budi")

Pada definisi def sapa(nama):, nama adalah parameter. Nilai "Andi" dan "Budi" adalah argumen yang diberikan saat pemanggilan. Fungsi yang sama menghasilkan sapaan berbeda karena argumennya berbeda.

Fungsi dengan lebih dari satu parameter

Parameter dipisahkan dengan tanda koma. Urutan argumen saat pemanggilan harus sesuai dengan urutan parameter pada definisi fungsi. 

def luas_persegi_panjang(panjang, lebar):
    luas = panjang * lebar
    print("Luas persegi panjang:", luas)

luas_persegi_panjang(8, 5)
luas_persegi_panjang(10, 3)

Pemanggilan luas_persegi_panjang(8, 5) memberikan nilai 8 ke parameter panjang dan 5 ke parameter lebar. Pemanggilan kedua menggunakan nilai yang berbeda sehingga hasilnya juga berbeda. 

def rata_rata(a, b, c):
    hasil = (a + b + c) / 3
    print("Rata-rata:", hasil)

rata_rata(80, 90, 100)

Fungsi rata_rata() memiliki tiga parameter. Jika jumlah argumen tidak sesuai dengan jumlah parameter, Python akan menampilkan TypeError. Pastikan setiap parameter mendapatkan nilai yang sesuai saat fungsi dipanggil.

7.3 Fungsi yang Mengembalikan Nilai dengan return

Kata kunci return digunakan untuk mengembalikan nilai dari fungsi kepada bagian program yang memanggilnya. Nilai tersebut dapat disimpan dalam variabel, dicetak, atau diolah lagi.

Mengembalikan hasil perhitungan

def tambah(a, b):
    return a + b

hasil = tambah(5, 3)
print("Hasil:", hasil)
print("Dua kali hasil:", hasil * 2)

Fungsi tambah() mengembalikan nilai 8. Nilai itu disimpan pada variabel hasil, lalu dapat digunakan untuk perhitungan berikutnya. Berbeda dari print() yang hanya menampilkan nilai, return memberikan nilai kepada pemanggil.

Return di tengah fungsi

Ketika Python menjalankan return, fungsi langsung berhenti. Baris setelah return tidak akan dijalankan. Karena itu, return dapat dipakai untuk mengembalikan hasil lebih awal. 

def cek_kelulusan(nilai):
    if nilai >= 75:
        return "Lulus"
    return "Belum lulus"

print(cek_kelulusan(80))
print(cek_kelulusan(60))

Jika nilai 80, kondisi terpenuhi dan fungsi mengembalikan "Lulus". Jika nilai 60, kondisi tidak terpenuhi sehingga fungsi melanjutkan ke return "Belum lulus".

Mengembalikan beberapa nilai

Sebuah fungsi dapat mengembalikan beberapa nilai sekaligus. Nilai-nilai tersebut dikembalikan sebagai tuple dan dapat diterima dengan beberapa variabel. 

def statistik(a, b, c):
    total = a + b + c
    rata_rata = total / 3
    return total, rata_rata

total, rata = statistik(80, 90, 100)
print("Total:", total)
print("Rata-rata:", rata)

Hasilnya adalah Total: 270 dan Rata-rata: 90.0. Perhatikan bahwa total dan rata_rata di dalam fungsi adalah variabel lokal yang akan dibahas pada subbab berikutnya.

7.4 Fungsi dan Prosedur

Dalam pemrograman, fungsi biasanya mengembalikan nilai, sedangkan prosedur melakukan suatu tindakan tanpa mengembalikan nilai yang akan diolah lagi. Di Python, keduanya dibuat dengan def. Istilah prosedur dipakai untuk fungsi yang tidak memiliki return atau tidak mengembalikan nilai yang berguna.

Perbandingan fungsi dan prosedur

def cetak_luas(panjang, lebar):
    print("Luas:", panjang * lebar)

def hitung_luas(panjang, lebar):
    return panjang * lebar

cetak_luas(4, 3)

luas = hitung_luas(4, 3)
print("Luas dari return:", luas)
print("Dua kali luas:", luas * 2)

cetak_luas() adalah prosedur karena langsung mencetak hasil. hitung_luas() adalah fungsi karena mengembalikan nilai yang dapat disimpan dan digunakan lagi. Hasil hitung_luas(4, 3) dapat dikalikan dua, sedangkan hasil cetak_luas(4, 3) tidak dapat diolah karena hanya ditampilkan.

Fungsi tanpa return mengembalikan None

def sapa():
    print("Halo!")

hasil = sapa()
print("Nilai kembalian:", hasil)

Outputnya adalah Halo! lalu Nilai kembalian: None. None adalah nilai khusus Python yang berarti tidak ada nilai. Jadi, fungsi yang tidak memiliki return tetap mengembalikan None secara otomatis.

Gunakan prosedur jika tugasnya hanya menampilkan informasi atau melakukan efek samping. Gunakan fungsi dengan return jika hasilnya masih akan dihitung, dibandingkan, atau diolah oleh bagian program lain.

7.5 Variabel Lokal dan Global

Ruang lingkup atau scope menentukan di bagian mana sebuah variabel dapat digunakan. Variabel yang dibuat di dalam fungsi bersifat lokal, sedangkan variabel yang dibuat di luar fungsi bersifat global.

Variabel lokal

Variabel lokal hanya dapat diakses di dalam fungsi tempat variabel itu dibuat. Variabel lokal juga dibuat ulang setiap kali fungsi dipanggil. 

def hitung():
    hasil = 10 + 5
    print("Hasil di dalam fungsi:", hasil)

hitung()

Variabel hasil adalah variabel lokal. Variabel itu tidak tersedia di luar fungsi hitung().

Variabel global

Variabel global dibuat di luar fungsi dan dapat dibaca dari dalam fungsi. Python akan mencari nama variabel di lingkup lokal terlebih dahulu, lalu ke lingkup global. 

nama = "Andi"

def sapa():
    print("Halo,", nama)

sapa()
print("Nama dari luar:", nama)

Karena nama tidak dibuat di dalam fungsi, Python menemukannya di lingkup global. Fungsi dapat membaca variabel global tanpa kata kunci tambahan.

Variabel lokal menutupi variabel global

nama = "Andi"

def ubah_nama():
    nama = "Budi"
    print("Di dalam fungsi:", nama)

ubah_nama()
print("Di luar fungsi:", nama)

Di dalam fungsi, nama = "Budi" membuat variabel lokal baru. Variabel lokal itu menutupi variabel global selama fungsi berjalan, tetapi variabel global di luar fungsi tetap bernilai "Andi".

Mengubah variabel global dengan global

Untuk mengubah variabel global dari dalam fungsi, gunakan kata kunci global sebelum nama variabel. Penggunaannya sebaiknya dibatasi agar alur program tetap mudah dipahami. 

skor = 0

def tambah_skor():
    global skor
    skor = skor + 10

tambah_skor()
tambah_skor()
print("Skor akhir:", skor)

Tanpa global skor, baris skor = skor + 10 akan membuat variabel lokal baru dan menimbulkan UnboundLocalError saat membaca skor. Dengan global skor, fungsi mengubah variabel global yang sama.

7.6 Urutan Pencarian Local-Global-Built-in dan NameError

Ketika Python menemukan nama variabel atau fungsi, Python mencarinya secara berurutan: Local, lalu Global, lalu Built-in. Urutan ini sering disingkat L-G-B.

  • Local adalah nama yang dibuat di dalam fungsi, termasuk parameter dan variabel lokal.
  • Global adalah nama yang dibuat di luar fungsi pada tingkat utama program.
  • Built-in adalah nama bawaan Python, misalnya print, len, dan sum.

Pencarian sampai ke built-in

def tampilkan(data):
    panjang = len(data)
    print("Panjang data:", panjang)

tampilkan([10, 20, 30, 40])

Nama data dan panjang ditemukan di lingkup lokal. Nama len tidak ada di lokal maupun global, sehingga Python mencarinya di built-in dan menemukan fungsi len().

NameError ketika nama tidak ditemukan

Jika nama tidak ditemukan di local, global, maupun built-in, Python menampilkan NameError. NameError juga muncul jika kita mengakses variabel lokal dari luar fungsi atau salah mengetik nama variabel. 

def hitung():
    hasil = 10
    return hasil

print("Nilai:", hitung())

# Baris berikut akan menghasilkan NameError karena hasil bersifat lokal.
# print(hasil)

Kode di atas berjalan dan menampilkan Nilai: 10. Namun, jika baris komentar print(hasil) dijalankan, Python akan menampilkan NameError: name 'hasil' is not defined. 

nama = "Andi"

def sapa():
    print("Halo,", nama)

    # Baris berikut akan menghasilkan NameError karena umur tidak ada.
    # print(umur)

sapa()

Fungsi sapa() menemukan nama di lingkup global. Sebaliknya, umur tidak ada di local, global, maupun built-in, sehingga akses terhadap umur akan menghasilkan NameError.

Hindari juga menggunakan nama built-in seperti len atau sum sebagai nama variabel. Jika nama built-in ditutupi oleh variabel lain, fungsi bawaan tersebut tidak dapat digunakan dengan benar.

Rangkuman

  • Fungsi adalah blok kode bernama yang dapat dipanggil berulang kali untuk menghindari duplikasi dan membuat program lebih terstruktur.
  • Fungsi dibuat dengan def, diikuti nama fungsi, tanda kurung, titik dua, dan isi fungsi yang diindentasi.
  • Parameter adalah variabel pada definisi fungsi, sedangkan argumen adalah nilai yang diberikan saat fungsi dipanggil.
  • return mengembalikan nilai kepada pemanggil dan langsung mengakhiri fungsi. Fungsi tanpa return menghasilkan None.
  • Fungsi mengembalikan nilai, sedangkan prosedur melakukan tindakan tanpa mengembalikan nilai yang akan diolah lagi.
  • Variabel lokal hanya berlaku di dalam fungsi. Variabel global dapat dibaca dari dalam fungsi, tetapi perlu global jika ingin diubah.
  • Python mencari nama dengan urutan Local, Global, lalu Built-in. Jika nama tidak ditemukan, Python menampilkan NameError.

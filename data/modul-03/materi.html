3.1 Operator, Operand, Unary, dan Binary

Operator adalah simbol atau tanda yang memberi tahu Python operasi apa yang harus dilakukan. Nilai atau variabel yang dikenai operasi disebut operand. 

hasil = 10 + 5
print(hasil)  # 15

Pada ekspresi 10 + 5, angka 10 dan 5 adalah operand, sedangkan + adalah operator. Operand tidak harus berupa angka langsung; operand juga dapat berupa variabel. 

umur = 20
batas = 17

print(umur >= batas)  # True

Pada contoh tersebut, umur dan batas menjadi operand, sedangkan >= adalah operator perbandingan.

Operator unary

Operator unary hanya membutuhkan satu operand. Contoh yang paling sederhana adalah tanda minus dan plus untuk menentukan tanda sebuah nilai. 

nilai = 10

print(-nilai)  # -10
print(+nilai)  # 10

Tanda minus unary mengubah tanda nilai, sedangkan tanda plus unary tidak mengubah nilainya.

Operator binary

Operator binary membutuhkan dua operand. Operator aritmatika dan perbandingan yang akan dipelajari berikutnya termasuk operator binary. 

print(10 + 5)   # 15
print(10 > 5)   # True

Sebagian operator dapat berperan sebagai unary atau binary tergantung konteksnya. Tanda - pada -5 adalah unary, sedangkan pada 10 - 5 adalah binary.

3.2 Operator Aritmatika

Operator aritmatika digunakan untuk melakukan perhitungan matematika. Python menyediakan lima operator aritmatika dasar yang akan kita pelajari pada modul ini.

  • + untuk penjumlahan.
  • - untuk pengurangan.
  • * untuk perkalian.
  • / untuk pembagian.
  • % untuk sisa hasil pembagian (modulus).

Penjumlahan dan pengurangan

a = 10
b = 3

print(a + b)  # 13
print(a - b)  # 7
print(b - a)  # -7

Operator + juga dapat menggabungkan dua string, seperti yang sudah dipelajari pada Modul 2. Jenis operand menentukan hasil operasinya.

Perkalian dan pembagian

print(10 * 3)  # 30
print(10 / 2)  # 5.0
print(10 / 4)  # 2.5

Pembagian dengan operator / selalu menghasilkan tipe float, termasuk ketika hasilnya bilangan bulat. Contohnya 10 / 2 menghasilkan 5.0, bukan 5.

Modulus

Operator % menghasilkan sisa hasil pembagian. Operator ini berguna untuk mengetahui apakah sebuah bilangan habis dibagi atau tidak. 

print(10 % 3)  # 1
print(12 % 4)  # 0
print(17 % 5)  # 2

Jika hasil modulus adalah 0, bilangan tersebut habis dibagi. Contohnya 12 % 4 menghasilkan 0.

Urutan operasi dan tanda kurung

Jika terdapat beberapa operator dalam satu ekspresi, perkalian dan pembagian dikerjakan lebih dahulu daripada penjumlahan dan pengurangan. Gunakan tanda kurung jika ingin mengubah urutan tersebut. 

print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20

3.3 Operator Perbandingan

Operator perbandingan digunakan untuk membandingkan dua nilai. Hasil dari perbandingan adalah nilai boolean, yaitu True atau False. Operator perbandingan akan banyak dipakai pada materi percabangan.

  • == untuk memeriksa apakah dua nilai sama.
  • != untuk memeriksa apakah dua nilai berbeda.
  • > untuk memeriksa apakah nilai kiri lebih besar.
  • < untuk memeriksa apakah nilai kiri lebih kecil.
  • >= untuk memeriksa apakah nilai kiri lebih besar atau sama dengan nilai kanan.
  • <= untuk memeriksa apakah nilai kiri lebih kecil atau sama dengan nilai kanan. 
umur = 20

print(umur == 20)  # True
print(umur != 20)  # False
print(umur > 17)   # True
print(umur < 17)   # False
print(umur >= 20)  # True
print(umur <= 19)  # False

Perbedaan = dan ==

Tanda = adalah operator penugasan untuk mengisi nilai ke variabel. Tanda == adalah operator perbandingan untuk memeriksa apakah dua nilai sama. 

nilai = 10       # mengisi nilai 10 ke variabel nilai
print(nilai == 10)  # True, karena 10 sama dengan 10
print(nilai == 5)   # False

Perbandingan juga dapat dilakukan pada string. Perbandingan string bersifat case-sensitive, sehingga huruf besar dan kecil dibedakan. 

print("Python" == "Python")  # True
print("Python" == "python")  # False

3.4 Operator Penugasan

Operator penugasan digunakan untuk memberikan nilai ke variabel. Operator = adalah bentuk dasar yang sudah digunakan pada modul sebelumnya. 

skor = 10
print(skor)  # 10

Operator penugasan ringkas

Python menyediakan bentuk ringkas untuk mengubah nilai variabel berdasarkan nilai sebelumnya. Bentuk ini disebut operator penugasan gabungan.

  • += menambahkan nilai ke variabel.
  • -= mengurangi nilai variabel.
  • *= mengalikan nilai variabel.
  • /= membagi nilai variabel.
  • %= mengambil sisa hasil pembagian variabel.
nilai = 20

nilai += 5
print(nilai)  # 25

nilai -= 3
print(nilai)  # 22

nilai *= 2
print(nilai)  # 44

nilai /= 4
print(nilai)  # 11.0

nilai %= 3
print(nilai)  # 2.0

Setiap bentuk ringkas memiliki bentuk panjang yang setara. Contohnya nilai += 5 sama dengan nilai = nilai + 5, sedangkan nilai *= 2 sama dengan nilai = nilai * 2.

Perhatikan bahwa /= menghasilkan nilai float. Setelah nilai /= 4, nilai 44 berubah menjadi 11.0, bukan 11.

Jangan menukar operator penugasan = dengan operator perbandingan ==. Keduanya memiliki fungsi yang berbeda.

3.5 Penerapan Operator pada Perhitungan

Operator aritmatika dapat digunakan untuk menyelesaikan perhitungan sederhana. Perhatikan empat contoh berikut.

Luas permukaan kubus

Luas permukaan kubus dihitung dengan rumus 6 * sisi * sisi. 

sisi = 5
luas_kubus = 6 * sisi * sisi

print("Luas kubus:", luas_kubus)  # Luas kubus: 150

Volume balok

Volume balok dihitung dengan rumus panjang * lebar * tinggi. 

panjang = 10
lebar = 6
tinggi = 4

volume_balok = panjang * lebar * tinggi
print("Volume balok:", volume_balok)  # Volume balok: 240

Energi potensial

Energi potensial dihitung dengan rumus massa * gravitasi * ketinggian. 

massa = 2
gravitasi = 9.8
ketinggian = 5

energi_potensial = massa * gravitasi * ketinggian
print("Energi potensial:", energi_potensial)  # Energi potensial: 98.0

Konversi dolar ke rupiah

Nilai rupiah dihitung dengan mengalikan jumlah dolar dengan kurs. 

dolar = 10
kurs = 16000

rupiah = dolar * kurs
print("Rupiah:", rupiah)  # Rupiah: 160000

Pola perhitungan tersebut akan digunakan pada latihan Modul 3. Kamu akan menghitung keempat nilai dan menampilkannya dengan label yang sesuai.

Rangkuman

  • Operator adalah simbol yang melakukan operasi, sedangkan operand adalah nilai atau variabel yang dikenai operasi.
  • Operator unary membutuhkan satu operand, seperti -5. Operator binary membutuhkan dua operand, seperti 10 + 5.
  • Operator aritmatika meliputi +, -, *, /, dan %. Pembagian / menghasilkan float, sedangkan % menghasilkan sisa pembagian.
  • Operator perbandingan meliputi ==, !=, >, <, >=, dan <=. Hasilnya berupa True atau False.
  • Operator penugasan = mengisi nilai, sedangkan +=, -=, *=, /=, dan %= mengubah nilai berdasarkan nilai sebelumnya.
  • Operator aritmatika dapat diterapkan pada perhitungan luas kubus, volume balok, energi potensial, dan konversi dolar ke rupiah.

6.1 Mengenal Struktur Data: List, Tuple, dan Dictionary

Struktur data adalah cara menyimpan dan mengatur banyak nilai dalam satu tempat. Selama ini kita menyimpan satu nilai pada satu variabel. Dengan struktur data, beberapa nilai dapat dikelompokkan dan diolah bersama-sama.

Python memiliki tiga struktur data dasar yang akan dipelajari pada modul ini, yaitu list, tuple, dan dictionary. Ketiganya dapat menyimpan banyak item, tetapi memiliki sifat dan cara akses yang berbeda. 

buah_list = ["apel", "jeruk", "mangga"]
buah_tuple = ("apel", "jeruk", "mangga")
buah_dict = {"apel": 10000, "jeruk": 8000, "mangga": 12000}

print(buah_list[0])
print(buah_tuple[1])
print(buah_dict["mangga"])
print(len(buah_list))
print(len(buah_tuple))
print(len(buah_dict))

List dan tuple menyimpan item secara berurutan sehingga diakses dengan indeks angka. Dictionary menyimpan pasangan key-value sehingga diakses dengan key, bukan dengan urutan posisi.

Perbandingan singkat

  • List ditulis dengan kurung siku [ ... ]. List bersifat mutable, yaitu isinya dapat diubah setelah dibuat. Item list memiliki indeks mulai dari 0.
  • Tuple ditulis dengan kurung biasa ( ... ). Tuple bersifat immutable, yaitu isinya tidak dapat diubah setelah dibuat. Item tuple juga memiliki indeks.
  • Dictionary ditulis dengan kurung kurawal { ... }. Setiap item terdiri atas key dan value. Dictionary bersifat mutable, tetapi aksesnya menggunakan key yang unik.

Ketiganya dapat berisi tipe data campuran. Namun, key pada dictionary harus berupa tipe data yang tidak dapat diubah, misalnya string atau angka. Nilai pada dictionary boleh berupa tipe data apa pun, termasuk list.

Pada editor PYLearn, nilai diisi langsung di dalam kode karena fungsi input() belum didukung. Kamu tetap dapat mengubah nilai pada kode untuk mencoba setiap contoh.

6.2 List: Membuat dan Mengakses Elemen

List adalah kumpulan item terurut yang ditulis di antara kurung siku. Setiap item dipisahkan dengan tanda koma. List dapat berisi string, angka, boolean, bahkan list lain. 

buah = ["apel", "jeruk", "mangga"]
campuran = ["Andi", 20, 3.5, True]
kosong = []

print(buah)
print(campuran)
print(kosong)

List buah berisi tiga string. List campuran menunjukkan bahwa satu list boleh berisi tipe data yang berbeda. List kosong dibuat dengan [].

Mengakses item dengan indeks

Indeks list dimulai dari 0. Item pertama berada pada indeks 0, item kedua pada indeks 1, dan seterusnya. Indeks negatif menghitung dari akhir list. 

buah = ["apel", "jeruk", "mangga", "pisang"]

print(buah[0])
print(buah[2])
print(buah[-1])
print(buah[-2])
print(len(buah))

buah[0] menghasilkan apel, sedangkan buah[-1] menghasilkan item terakhir, yaitu pisang. Fungsi len(buah) menghasilkan jumlah item pada list, yaitu 4.

Jika indeks yang digunakan melebihi jumlah item, Python akan menampilkan IndexError. Karena indeks dimulai dari 0, indeks terakhir pada list berisi 4 item adalah 3.

Mengubah item list

Karena list bersifat mutable, item dapat diganti dengan menuliskan indeks diikuti tanda sama dengan dan nilai baru. 

buah = ["apel", "jeruk", "mangga"]
buah[1] = "pisang"

print(buah)

Item pada indeks 1 yang semula jeruk diganti menjadi pisang. Perubahan ini langsung tersimpan pada list yang sama.

6.3 List: Menambah, Mengubah, dan Menghapus Elemen

List menyediakan beberapa cara untuk menambah dan menghapus item. Pilih cara yang sesuai dengan kebutuhan: berdasarkan posisi atau berdasarkan nilai.

Menambah item dengan append() dan insert()

Metode append() menambahkan item di akhir list. Metode insert() menambahkan item pada indeks tertentu dan menggeser item setelahnya. 

buah = ["apel", "jeruk"]

buah.append("mangga")
buah.insert(1, "pisang")

print(buah)

append("mangga") menambahkan mangga di akhir. Setelah itu, insert(1, "pisang") menyisipkan pisang pada indeks 1 sehingga hasilnya adalah ['apel', 'pisang', 'jeruk', 'mangga'].

Menghapus item dengan del

Perintah del menghapus item berdasarkan indeksnya. 

buah = ["apel", "jeruk", "mangga"]

del buah[1]
print(buah)

Item pada indeks 1, yaitu jeruk, dihapus. Item setelahnya bergeser sehingga list menjadi ['apel', 'mangga'].

Menghapus item dengan remove()

Metode remove() menghapus item berdasarkan nilainya. Jika nilai muncul lebih dari sekali, hanya kemunculan pertama yang dihapus. 

buah = ["apel", "jeruk", "mangga", "jeruk"]

buah.remove("jeruk")
print(buah)

Hanya jeruk pertama yang dihapus. Hasilnya adalah ['apel', 'mangga', 'jeruk']. Jika nilai yang dicari tidak ada, Python akan menampilkan ValueError.

Ringkasnya, gunakan del jika ingin menghapus berdasarkan posisi, dan gunakan remove() jika ingin menghapus berdasarkan nilai.

6.4 List: Pemotongan, Operasi, dan Perulangan Bersarang

Selain mengambil satu item, list dapat dipotong untuk mengambil beberapa item sekaligus. List juga dapat digabung, diulang, dan disusun menjadi list multidimensi.

Pemotongan list (slicing)

Slicing menggunakan bentuk list[mulai:selesai]. Nilai mulai ikut diambil, sedangkan nilai selesai tidak ikut diambil. 

angka = [10, 20, 30, 40, 50]

print(angka[1:4])
print(angka[:3])
print(angka[2:])
print(angka[-3:])
print(angka[0:5:2])

angka[1:4] menghasilkan [20, 30, 40]. angka[:3] mengambil dari awal sampai sebelum indeks 3. angka[2:] mengambil dari indeks 2 sampai akhir. Slicing tidak mengubah list asli kecuali hasilnya disimpan kembali ke variabel.

Penggabungan dan pengulangan

Operator + menggabungkan dua list, sedangkan operator * mengulang isi list sebanyak jumlah pengulangan. 

awal = [1, 2]
akhir = [3, 4]

gabung = awal + akhir
ulang = ["A", "B"] * 3

print(gabung)
print(ulang)

Hasil penggabungan adalah [1, 2, 3, 4], sedangkan hasil pengulangan adalah ['A', 'B', 'A', 'B', 'A', 'B'].

List multidimensi

List multidimensi adalah list yang berisi list lain. Untuk mengakses item di dalamnya, gunakan dua indeks: indeks list luar, lalu indeks list dalam. 

kelas = [
    ["Andi", 80],
    ["Budi", 90],
    ["Citra", 85]
]

print(kelas[0])
print(kelas[0][0])
print(kelas[2][1])

kelas[0] menghasilkan ['Andi', 80], sedangkan kelas[0][0] menghasilkan Andi. Nilai kelas[2][1] adalah nilai Citra, yaitu 85.

Perulangan bersarang pada list

Perulangan bersarang berarti ada perulangan di dalam perulangan. Pada list multidimensi, perulangan luar menelusuri setiap baris, sedangkan perulangan dalam menelusuri setiap item pada baris tersebut. 

kelas = [
    ["Andi", 80],
    ["Budi", 90],
    ["Citra", 85]
]

for baris in kelas:
    for data in baris:
        print(data)

Outputnya berurutan: Andi, 80, Budi, 90, Citra, lalu 85. Perulangan dalam dijalankan sampai selesai untuk setiap baris sebelum berpindah ke baris berikutnya.

6.5 Tuple: Struktur Data yang Tidak Dapat Diubah

Tuple adalah kumpulan item terurut yang bersifat immutable. Artinya, setelah tuple dibuat, item di dalamnya tidak dapat diubah, ditambah, atau dihapus. Tuple dapat berisi tipe data campuran dan boleh memiliki nilai duplikat.

Membuat tuple

Tuple dapat ditulis dengan tanda kurung biasa atau tanpa tanda kurung selama item dipisahkan dengan koma. 

koordinat = (10, 20)
warna = "merah", "hijau", "biru"

print(koordinat)
print(warna)

koordinat dan warna sama-sama tuple. Tanda kurung bersifat opsional, tetapi penggunaannya membuat kode lebih mudah dibaca.

Tuple kosong dan tuple satu elemen

Tuple kosong ditulis (). Tuple dengan satu elemen wajib diakhiri tanda koma, misalnya ("apel",). Tanpa tanda koma, tanda kurung hanya mengelompokkan nilai dan hasilnya bukan tuple. 

kosong = ()
satu = ("apel",)
bukan_tuple = ("apel")

print(kosong)
print(satu)
print(bukan_tuple)
print(len(kosong))
print(len(satu))

satu adalah tuple dengan satu elemen, sedangkan bukan_tuple hanyalah string. Panjang tuple kosong adalah 0 dan panjang tuple satu elemen adalah 1.

Akses, slicing, dan len()

Cara mengakses tuple sama seperti list, yaitu menggunakan indeks. Tuple juga dapat dipotong dan dihitung panjangnya dengan len(). 

angka = (10, 20, 30, 40, 50)

print(angka[0])
print(angka[-1])
print(angka[1:4])
print(len(angka))

Hasilnya adalah 10, 50, (20, 30, 40), dan 5. Perhatikan bahwa hasil slicing tuple tetap berupa tuple.

Tuple bersarang

Tuple juga dapat berisi tuple lain. Item di dalam tuple bersarang diakses dengan indeks tambahan. 

data = ("Andi", (80, 90, 85))

print(data[0])
print(data[1])
print(data[1][1])

data[0] menghasilkan Andi, sedangkan data[1][1] menghasilkan nilai kedua di dalam tuple nilai, yaitu 90.

Sequence unpacking

Sequence unpacking membagi item tuple menjadi beberapa variabel. Jumlah variabel di kiri harus sama dengan jumlah item di kanan. 

data = ("Andi", 20, "Informatika")
nama, umur, jurusan = data

print(nama)
print(umur)
print(jurusan)

Setelah unpacking, nama berisi Andi, umur berisi 20, dan jurusan berisi Informatika.

Mengapa tuple tidak dapat diubah?

angka = (1, 2, 3)
print(angka[0])

# Baris berikut akan menghasilkan TypeError karena tuple tidak dapat diubah.
# angka[0] = 10

Jika baris komentar di atas dijalankan, Python menampilkan TypeError: 'tuple' object does not support item assignment. Sifat immutable membuat tuple cocok untuk data yang harus tetap, misalnya koordinat atau data konfigurasi.

6.6 Dictionary: Mengakses dan Menelusuri Data

Dictionary menyimpan data dalam pasangan key dan value. Key berfungsi sebagai penanda yang unik, sedangkan value adalah nilai yang terkait dengan key tersebut. Dictionary ditulis dengan kurung kurawal.

Deklarasi dictionary

Dictionary dapat dibuat dengan literal { } atau konstruktor dict(). 

harga = {"apel": 10000, "jeruk": 8000, "mangga": 12000}
harga_lain = dict(apel=10000, jeruk=8000, mangga=12000)

print(harga)
print(harga_lain)

Pada dict(), key ditulis seperti nama parameter tanpa tanda kutip. Cara ini cocok untuk key berupa string sederhana.

Isi bervariasi dan akses dengan key

Value dictionary boleh berupa tipe data apa pun. Contoh berikut menyimpan string, angka, boolean, dan list dalam satu dictionary. 

siswa = {
    "nama": "Andi",
    "umur": 20,
    "aktif": True,
    "nilai": [80, 90, 85]
}

print(siswa["nama"])
print(siswa["nilai"][1])
print(siswa.get("umur"))
print(siswa.get("alamat"))
print(siswa.get("alamat", "Belum diisi"))
print(len(siswa))

Akses dengan siswa["nama"] menghasilkan nilai dari key nama. Metode get() digunakan untuk mengambil nilai dengan aman. Jika key tidak ada, get() menghasilkan None atau nilai default yang diberikan.

Sebaliknya, akses langsung seperti siswa["alamat"] untuk key yang tidak ada akan menghasilkan KeyError. Fungsi len(siswa) menghitung jumlah pasangan key-value, yaitu 4.

Perulangan dengan key

Jika dictionary diulang secara langsung, yang diperoleh adalah key-nya. 

harga = {"apel": 10000, "jeruk": 8000, "mangga": 12000}

for buah in harga:
    print(buah)

Outputnya adalah apel, jeruk, dan mangga. Untuk mengambil nilainya, gunakan key tersebut di dalam perulangan.

Perulangan dengan items()

Metode items() menghasilkan pasangan key dan value. Keduanya dapat ditangkap dengan dua variabel. 

harga = {"apel": 10000, "jeruk": 8000, "mangga": 12000}

for buah, nilai in harga.items():
    print("Harga", buah, "=", nilai)

Setiap iterasi menghasilkan satu key dan satu value. Outputnya adalah Harga apel = 10000, lalu Harga jeruk = 8000, dan Harga mangga = 12000.

6.7 Dictionary: Menambah, Mengubah, dan Menghapus Data

Dictionary bersifat mutable. Item dapat ditambah, diubah, atau dihapus menggunakan key sebagai penanda.

Menambah dan mengubah item

Jika key belum ada, penugasan akan menambahkan pasangan baru. Jika key sudah ada, penugasan akan mengubah value lama. 

harga = {"apel": 10000, "jeruk": 8000}

harga["mangga"] = 12000
harga["apel"] = 11000

print(harga)

harga["mangga"] = 12000 menambahkan key baru, sedangkan harga["apel"] = 11000 mengubah value apel dari 10000 menjadi 11000.

Memperbarui dengan update()

Metode update() dapat menambahkan beberapa pasangan sekaligus. Jika key sudah ada, nilainya akan ditimpa. 

harga = {"apel": 10000, "jeruk": 8000}

harga.update({"jeruk": 9000, "mangga": 12000})
print(harga)

Key jeruk diperbarui menjadi 9000, sedangkan key mangga ditambahkan dengan nilai 12000.

Menghapus dengan del dan pop()

del menghapus pasangan berdasarkan key. Metode pop() juga menghapus pasangan berdasarkan key, tetapi mengembalikan value yang dihapus. 

harga = {"apel": 10000, "jeruk": 8000, "mangga": 12000}

del harga["jeruk"]
dihapus = harga.pop("mangga")

print(harga)
print("Nilai yang dihapus:", dihapus)

Setelah kedua penghapusan, dictionary hanya berisi apel. Nilai 12000 dari key mangga disimpan pada variabel dihapus.

Menghapus semua item dengan clear()

harga = {"apel": 10000, "jeruk": 8000}

harga.clear()
print(harga)
print(len(harga))

clear() mengosongkan dictionary, sehingga hasilnya {} dan panjangnya 0.

Ringkasnya, gunakan del jika tidak memerlukan nilai yang dihapus, pop() jika nilai yang dihapus masih dibutuhkan, dan clear() jika seluruh isi dictionary ingin dihapus.

Rangkuman

  • List menggunakan [ ], bersifat mutable, dan diakses dengan indeks. List dapat berisi tipe data campuran.
  • append() menambah item di akhir, insert() menambah pada indeks tertentu, del menghapus berdasarkan indeks, dan remove() menghapus berdasarkan nilai.
  • Slicing list[mulai:selesai] mengambil sebagian item. Operator + menggabungkan list dan * mengulang list.
  • List multidimensi berisi list lain dan dapat ditelusuri dengan perulangan bersarang.
  • Tuple menggunakan ( ), bersifat immutable, dan tetap dapat diakses dengan indeks, dipotong, serta di-unpack.
  • Tuple satu elemen memerlukan tanda koma, misalnya ("apel",).
  • Dictionary menyimpan pasangan key-value, diakses dengan key atau get(), dan dapat ditelusuri dengan items().
  • Item dictionary dapat ditambah atau diubah dengan penugasan dan update(), lalu dihapus dengan del, pop(), atau clear().

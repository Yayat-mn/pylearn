4.1 Konsep Percabangan dan Struktur if

Percabangan atau control flow adalah cara program memilih jalur yang akan dijalankan berdasarkan suatu kondisi. Dengan percabangan, program tidak harus menjalankan semua perintah secara berurutan; sebagian perintah hanya dijalankan jika kondisinya terpenuhi.

Struktur dasar percabangan di Python adalah if. Perintah di dalam blok if akan dijalankan apabila kondisi bernilai True. Jika kondisi bernilai False, blok tersebut dilewati. 

nilai = 80

if nilai >= 75:
    print("Lulus")

Pada contoh tersebut, nilai >= 75 bernilai True karena 80 lebih besar atau sama dengan 75. Akibatnya, perintah print("Lulus") dijalankan.

Jika nilai variabel diubah menjadi 60, kondisi nilai >= 75 bernilai False. Blok if akan dilewati sehingga tidak ada output yang ditampilkan. 

nilai = 60

if nilai >= 75:
    print("Lulus")

Pada editor PYLearn, nilai variabel diisi langsung di dalam kode karena fungsi input() belum didukung. Kamu dapat mengubah nilai variabel untuk mencoba kondisi yang berbeda.

4.2 Indentasi, Titik Dua, dan Operator Relasi

Penulisan if di Python memiliki aturan yang harus diperhatikan agar program dapat berjalan.

Tanda titik dua

Baris if harus diakhiri dengan tanda titik dua (:). Tanda tersebut menandakan bahwa baris berikutnya adalah awal blok perintah. 

umur = 20

if umur >= 17:
    print("Boleh membuat SIM")

Jika tanda titik dua dihilangkan, Python akan menampilkan SyntaxError.

Indentasi

Perintah yang berada di dalam blok if harus diberi indentasi, yaitu menjorok ke dalam. Python mengenali blok berdasarkan indentasi. Empat spasi adalah ukuran yang umum dan disarankan. 

nilai = 90

if nilai >= 75:
    print("Nilai memenuhi syarat")
    print("Selamat!")

Kedua perintah print() berada di dalam blok yang sama karena memiliki indentasi yang sama. Jika baris perintah di dalam if tidak diberi indentasi, Python akan menampilkan IndentationError.

Hindari mencampur tab dan spasi dalam satu blok. Gunakan salah satu secara konsisten, misalnya empat spasi untuk setiap tingkat indentasi.

Operator relasi dalam kondisi

Kondisi pada if umumnya menggunakan operator relasi atau perbandingan. Operator == digunakan untuk memeriksa kesamaan, sedangkan = digunakan untuk mengisi nilai ke variabel. 

jawaban = "ya"

if jawaban == "ya":
    print("Silakan lanjut")

Contoh lain adalah perbandingan angka dengan operator >=, <=, >, dan <. 

suhu = 38

if suhu > 37:
    print("Suhu tubuh tinggi")

Hasil dari operator relasi adalah boolean, yaitu True atau False. Nilai boolean itulah yang menentukan apakah blok if dijalankan atau dilewati.

4.3 Percabangan if-else

Struktur if-else digunakan ketika terdapat dua pilihan keputusan. Jika kondisi pada if bernilai True, blok if dijalankan. Jika bernilai False, blok else yang dijalankan. 

nilai = 60

if nilai >= 75:
    print("Lulus")
else:
    print("Remedial")

Karena 60 >= 75 bernilai False, program menjalankan blok else dan menampilkan Remedial.

Perhatikan bahwa else tidak memiliki kondisi dan tetap diakhiri dengan tanda titik dua. Blok else hanya dijalankan jika semua kondisi sebelumnya tidak terpenuhi.

Dalam satu struktur if-else, hanya satu blok yang dijalankan. Blok if dan blok else tidak akan dijalankan bersamaan. 

umur = 20

if umur >= 17:
    print("Boleh membuat SIM")
else:
    print("Belum boleh membuat SIM")

4.4 Percabangan if-elif-else

Jika pilihan keputusan lebih dari dua, gunakan elif. elif adalah singkatan dari else if, yaitu kondisi tambahan yang diperiksa ketika kondisi sebelumnya tidak terpenuhi. 

nilai = 85

if nilai >= 90:
    grade = "A"
elif nilai >= 80:
    grade = "B"
elif nilai >= 70:
    grade = "C"
else:
    grade = "D"

print("Grade:", grade)  # Grade: B

Python memeriksa kondisi dari atas ke bawah. Kondisi nilai >= 90 bernilai False, lalu kondisi nilai >= 80 bernilai True. Program menjalankan blok tersebut dan melewati elif serta else berikutnya.

Urutan kondisi penting

Kondisi pada if-elif-else sebaiknya disusun dari yang paling spesifik atau paling ketat. Pada contoh grade, urutan dimulai dari nilai tertinggi. Jika kondisi nilai >= 70 diletakkan paling atas, nilai 95 akan langsung dianggap C karena kondisi itu sudah bernilai True. 

nilai = 95

if nilai >= 70:
    grade = "C"
elif nilai >= 80:
    grade = "B"
elif nilai >= 90:
    grade = "A"
else:
    grade = "D"

print("Grade:", grade)  # Grade: C

Contoh tersebut menunjukkan mengapa urutan kondisi harus diperhatikan. Meskipun nilainya 95, program berhenti pada kondisi pertama yang bernilai True.

Blok else bersifat opsional. Jika semua kondisi bernilai False dan tidak ada else, tidak ada blok tambahan yang dijalankan. 

nilai = 85

if nilai >= 90:
    print("Sangat baik")
elif nilai >= 80:
    print("Baik")
elif nilai >= 70:
    print("Cukup")

Pada contoh terakhir, nilai 85 memenuhi kondisi kedua sehingga program menampilkan Baik. Jika nilainya 60, tidak ada kondisi yang terpenuhi dan program tidak menampilkan apa pun.

4.5 Penerapan Percabangan

Percabangan dapat digunakan untuk menyelesaikan berbagai kasus sederhana. Perhatikan empat contoh berikut.

Remedi nilai

nilai = 65

if nilai >= 75:
    print("Lulus")
else:
    print("Remedial")

Karena nilai 65 belum mencapai batas 75, program menampilkan Remedial.

Bonus dan diskon belanja

total = 600000

if total >= 500000:
    bonus = "Voucher 50.000"
    diskon = total * 0.10
else:
    bonus = "Tidak ada bonus"
    diskon = 0

print("Bonus:", bonus)
print("Diskon:", diskon)
print("Total bayar:", total - diskon)

Karena total belanja mencapai 500000, pelanggan mendapatkan bonus dan diskon 10 persen. Diskonnya adalah 60000.0 sehingga total yang dibayar menjadi 540000.0.

Batas usia membuat SIM

umur = 20

if umur >= 17:
    print("Boleh membuat SIM")
else:
    print("Belum boleh membuat SIM")

Dengan umur 20, kondisi umur >= 17 bernilai True sehingga program menampilkan bahwa pengguna boleh membuat SIM.

Penentuan grade nilai

nilai = 85

if nilai >= 90:
    grade = "A"
elif nilai >= 80:
    grade = "B"
elif nilai >= 70:
    grade = "C"
else:
    grade = "D"

print("Grade:", grade)

Nilai 85 berada pada rentang 80 sampai 89 sehingga grade yang diperoleh adalah B.

Pola percabangan tersebut akan digunakan pada latihan Modul 4. Kamu akan menentukan grade nilai dan status pembuatan SIM berdasarkan variabel yang sudah disediakan.

Rangkuman

  • Percabangan membuat program memilih jalur berdasarkan kondisi. Struktur dasar di Python adalah if.
  • Baris if harus diakhiri tanda titik dua, dan blok di dalamnya harus diberi indentasi yang konsisten.
  • Operator == digunakan untuk membandingkan nilai, sedangkan = digunakan untuk mengisi nilai ke variabel.
  • if-else digunakan untuk dua pilihan keputusan. Blok else dijalankan jika kondisi if bernilai False.
  • if-elif-else digunakan untuk lebih dari dua pilihan. Kondisi diperiksa dari atas ke bawah dan blok pertama yang bernilai True akan dijalankan.
  • Percabangan dapat diterapkan pada kasus remedi, bonus dan diskon belanja, batas usia membuat SIM, serta penentuan grade nilai.

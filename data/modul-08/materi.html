8.1 Rancangan Program dan Data Global

Modul ini adalah puncak perjalanan belajar Python. Kita akan membangun Pustaka Mini, yaitu aplikasi sederhana untuk mengelola data buku. Program berjalan lewat menu di terminal dan menyimpan data di dalam memori selama program masih berjalan.

Di PYLearn, aplikasi ini dapat langsung dimainkan. Setelah kode dijalankan, program berhenti di setiap input() dan menunggu jawabanmu. Kamu dapat menambah, mengubah, dan menghapus buku dengan data pilihanmu sendiri.

Pustaka Mini menerapkan materi yang sudah dipelajari: variabel, tipe data, percabangan, perulangan, list, dictionary, dan fungsi. Setiap fitur dikerjakan oleh fungsi tersendiri agar program mudah dibaca dan diuji.

Fitur yang akan dibuat

  • Tampilkan buku — melihat seluruh data buku.
  • Tambah buku — menambahkan satu buku baru.
  • Ubah buku — memperbarui data buku yang sudah ada.
  • Hapus buku — menghapus buku setelah konfirmasi.
  • Keluar — menghentikan program dengan rapi.

Menyimpan banyak buku

Satu buku memiliki judul, penulis, tahun terbit, dan stok. Karena itu, satu buku paling tepat disimpan sebagai dictionary. Seluruh buku kemudian dikumpulkan dalam list. Struktur ini disebut list of dictionary. 

daftar_buku = [
    {"judul": "Python Dasar", "penulis": "Andi", "tahun": 2024, "stok": 3},
    {"judul": "Algoritma", "penulis": "Budi", "tahun": 2023, "stok": 2},
]

for buku in daftar_buku:
    print(buku["judul"], "-", buku["penulis"])

Setiap dictionary memakai kunci yang sama, yaitu judul, penulis, tahun, dan stok. Kunci yang seragam memudahkan fungsi lain membaca dan mengubah data.

Mengapa daftar_buku diletakkan di luar fungsi?

daftar_buku adalah variabel global karena dibuat di tingkat utama program, bukan di dalam fungsi. Semua fungsi dapat membacanya. Fungsi juga dapat menambah, mengubah, atau menghapus isi list tanpa menulis global, asalkan yang diubah adalah isi list, bukan nama variabelnya. 

daftar_buku = []

def tambah_cepat(judul):
    daftar_buku.append({"judul": judul, "penulis": "-", "tahun": 0, "stok": 0})

tambah_cepat("Belajar Python")
print(daftar_buku)

Namun, jika kita menulis daftar_buku = [] di dalam fungsi, Python membuat variabel lokal baru, bukan mengosongkan list global. Untuk proyek ini, kita hanya memakai append(), pop(), dan penggantian isi indeks sehingga global tidak diperlukan.

Rancangan menu

Pilihan Fungsi Tugas
1 show_data() Menampilkan seluruh buku.
2 insert_data() Menambahkan buku baru.
3 edit_data() Mengubah data buku.
4 delete_data() Menghapus buku.
5 exit() Keluar dari program.

Dengan rancangan ini, setiap fungsi memiliki satu tugas yang jelas. Pola tersebut akan memudahkan proses pengujian di subbab terakhir.

8.2 Menampilkan Daftar Buku dengan show_data()

Fungsi show_data() bertugas menampilkan seluruh isi daftar_buku. Agar pengguna mudah memilih buku saat mengubah atau menghapus, setiap buku diberi nomor urut mulai dari 1.

Menggunakan enumerate()

enumerate() menghasilkan pasangan nomor dan nilai saat kita melakukan perulangan. Parameter start=1 membuat penomoran dimulai dari satu, bukan nol. 

daftar_buku = [
    {"judul": "Python Dasar", "penulis": "Andi", "tahun": 2024, "stok": 3},
    {"judul": "Algoritma", "penulis": "Budi", "tahun": 2023, "stok": 2},
]

def show_data():
    print("\nDAFTAR BUKU")
    if not daftar_buku:
        print("Belum ada buku.")
        return

    for nomor, buku in enumerate(daftar_buku, start=1):
        print(
            f"{nomor}. {buku['judul']} | {buku['penulis']} | "
            f"{buku['tahun']} | stok {buku['stok']}"
        )

show_data()

Tanda | dipakai sebagai pemisah agar kolom mudah dibaca. F-string memudahkan penggabungan teks dan nilai variabel. Perhatikan bahwa kunci dictionary ditulis dengan tanda kutip di dalam f-string, misalnya {buku['judul']}.

Menangani daftar yang masih kosong

Jika daftar_buku kosong, perulangan tidak berjalan. Tanpa pemeriksaan, pengguna hanya melihat judul tanpa isi. Karena itu, fungsi menampilkan pesan khusus saat data kosong. 

daftar_buku = []

def show_data():
    print("\nDAFTAR BUKU")
    if not daftar_buku:
        print("Belum ada buku.")
        return

    for nomor, buku in enumerate(daftar_buku, start=1):
        print(f"{nomor}. {buku['judul']}")

show_data()

return menghentikan fungsi lebih awal. Baris perulangan di bawahnya tidak dijalankan ketika daftar kosong. Pola ini disebut early return dan membuat kode lebih mudah dibaca daripada menambahkan else yang panjang.

8.3 Menambah Buku dengan insert_data()

Fungsi insert_data() meminta empat data, lalu menambahkan dictionary baru ke daftar_buku dengan append(). Data tahun dan stok perlu diubah menjadi bilangan bulat memakai int().

Input interaktif di browser

Di Python biasa, program interaktif memakai input(). PYLearn menjalankan Python di browser dengan konsol interaktif: ketika program mencapai input(), program berhenti dan menampilkan kotak jawaban di bawah panel Output. Setelah kamu mengetik jawaban dan menekan Enter, program melanjutkan memakai jawaban itu.

Karena itu, tulis proyek ini seperti Python biasa. Tidak perlu fungsi bantuan atau antrean jawaban. Contoh di bawah dapat langsung dijalankan dari editor; isi judul, penulis, tahun, dan stok dengan data pilihanmu. 

daftar_buku = [
    {"judul": "Python Dasar", "penulis": "Andi", "tahun": 2024, "stok": 3},
]

def insert_data():
    print("\nTAMBAH BUKU")
    judul = input("Judul: ")
    penulis = input("Penulis: ")

    try:
        tahun = int(input("Tahun: "))
        stok = int(input("Stok: "))
    except ValueError:
        print("Tahun dan stok harus berupa angka.")
        return

    daftar_buku.append(
        {
            "judul": judul,
            "penulis": penulis,
            "tahun": tahun,
            "stok": stok,
        }
    )
    print(f"Buku '{judul}' berhasil ditambahkan.")

insert_data()
print(daftar_buku)

try-except ValueError menangani kesalahan ketika pengguna mengetik teks pada tahun atau stok. Tanpa penanganan, program berhenti dengan pesan error. Dengan penanganan, program memberi pesan dan kembali ke menu.

Mencoba dengan data sendiri

Setelah menekan Jalankan, jawab setiap prompt. Data yang kamu ketik tersimpan di daftar_buku selama sesi berjalan. Tekan Stop bila ingin mengubah kode, lalu jalankan lagi dari awal. Jangan lupa mengubah tahun dan stok dengan int() karena input() selalu menghasilkan string.

8.4 Mengubah Buku dengan edit_data()

Fungsi edit_data() menampilkan daftar lebih dulu agar pengguna mengetahui nomor buku yang akan diubah. Setelah nomor dimasukkan, fungsi meminta data baru dan mengganti dictionary pada indeks yang sesuai.

Nomor tampilan dan indeks list

Nomor yang dilihat pengguna dimulai dari 1, sedangkan indeks list dimulai dari 0. Jika pengguna memilih buku nomor 1, dictionary yang diubah berada pada indeks 0. Karena itu, program memakai daftar_buku[nomor - 1]. 

daftar_buku = [
    {"judul": "Python Dasar", "penulis": "Andi", "tahun": 2024, "stok": 3},
    {"judul": "Algoritma", "penulis": "Budi", "tahun": 2023, "stok": 2},
]

def show_data():
    print("\nDAFTAR BUKU")
    for nomor, buku in enumerate(daftar_buku, start=1):
        print(f"{nomor}. {buku['judul']} | {buku['penulis']} | stok {buku['stok']}")

def edit_data():
    print("\nUBAH BUKU")
    if not daftar_buku:
        print("Belum ada buku.")
        return

    show_data()

    try:
        nomor = int(input("Nomor buku: "))
    except ValueError:
        print("Nomor buku harus berupa angka.")
        return

    if nomor < 1 or nomor > len(daftar_buku):
        print("Nomor buku tidak valid.")
        return

    judul = input("Judul: ")
    penulis = input("Penulis: ")
    tahun = int(input("Tahun: "))
    stok = int(input("Stok: "))

    daftar_buku[nomor - 1] = {
        "judul": judul,
        "penulis": penulis,
        "tahun": tahun,
        "stok": stok,
    }
    print(f"Buku '{judul}' berhasil diubah.")

edit_data()
print(daftar_buku)

Pemeriksaan nomor < 1 or nomor > len(daftar_buku) mencegah indeks di luar jangkauan. Tanpa pemeriksaan itu, Python akan menampilkan IndexError ketika pengguna mengetik nomor yang tidak ada.

Mengubah satu bidang saja

Kode di atas mengganti seluruh dictionary agar sederhana. Jika hanya ingin mengubah stok, kita bisa menulis daftar_buku[nomor - 1]["stok"] = stok_baru. Kedua cara sama valid asalkan kunci dictionary tetap lengkap dan konsisten.

8.5 Menghapus Buku dengan delete_data()

Fungsi delete_data() meminta nomor buku, menampilkan daftar, lalu meminta konfirmasi. Konfirmasi penting karena penghapusan data tidak dapat dibatalkan setelah dijalankan.

Menggunakan pop()

pop(indeks) menghapus elemen pada indeks tertentu dan mengembalikan nilai yang dihapus. Nilai kembalian itu dapat dipakai untuk menampilkan judul buku yang berhasil dihapus. 

daftar_buku = [
    {"judul": "Python Dasar", "penulis": "Andi", "tahun": 2024, "stok": 3},
    {"judul": "Algoritma", "penulis": "Budi", "tahun": 2023, "stok": 2},
]

def show_data():
    print("\nDAFTAR BUKU")
    for nomor, buku in enumerate(daftar_buku, start=1):
        print(f"{nomor}. {buku['judul']} | {buku['penulis']}")

def delete_data():
    print("\nHAPUS BUKU")
    if not daftar_buku:
        print("Belum ada buku.")
        return

    show_data()

    try:
        nomor = int(input("Nomor buku: "))
    except ValueError:
        print("Nomor buku harus berupa angka.")
        return

    if nomor < 1 or nomor > len(daftar_buku):
        print("Nomor buku tidak valid.")
        return

    konfirmasi = input("Yakin hapus? (y/n): ").lower()
    if konfirmasi != "y":
        print("Penghapusan dibatalkan.")
        return

    buku = daftar_buku.pop(nomor - 1)
    print(f"Buku '{buku['judul']}' berhasil dihapus.")

delete_data()
print(daftar_buku)

lower() membuat jawaban Y dan y sama-sama diterima. Jika jawaban bukan y, fungsi berhenti tanpa mengubah data.

Alternatif del

Python juga menyediakan del daftar_buku[nomor - 1]. Bedanya, del tidak mengembalikan nilai yang dihapus. Untuk proyek ini, pop() lebih praktis karena judul buku bisa langsung dipakai pada pesan konfirmasi.

8.6 Menu, Main Loop, dan if __name__ == "__main__"

Menu membuat program dapat dipakai berulang kali tanpa menjalankannya ulang dari awal. Fungsi show_menu() menampilkan pilihan, sedangkan main() membaca pilihan dan memanggil fungsi yang sesuai.

Perulangan while True

while True berarti perulangan berjalan terus sampai ada perintah break. Program hanya keluar ketika pengguna memilih menu 5. Pilihan yang tidak dikenal tidak menghentikan program; pengguna diminta memilih lagi. 

# Pyodide menjalankan kode dengan __name__ = "builtins".
# Baris berikut menyamakannya dengan Python biasa.
if __name__ == "builtins":
    __name__ = "__main__"


daftar_buku = [
    {"judul": "Python Dasar", "penulis": "Andi", "tahun": 2024, "stok": 3},
]


def show_data():
    print("\nDAFTAR BUKU")
    for nomor, buku in enumerate(daftar_buku, start=1):
        print(f"{nomor}. {buku['judul']}")

def show_menu():
    print("\n=== PUSTAKA MINI ===")
    print("1. Tampilkan  2. Tambah  3. Ubah  4. Hapus  5. Keluar")

def exit():
    print("Terima kasih telah menggunakan Pustaka Mini.")
    return False

def main():
    while True:
        show_menu()
        pilihan = input("Pilih menu (1-5): ")

        if pilihan == "1":
            show_data()
        elif pilihan == "2":
            print("Menu tambah belum diisi pada contoh ini.")
        elif pilihan == "3":
            print("Menu ubah belum diisi pada contoh ini.")
        elif pilihan == "4":
            print("Menu hapus belum diisi pada contoh ini.")
        elif pilihan == "5":
            if not exit():
                break
        else:
            print("Pilihan tidak valid. Silakan pilih 1-5.")

if __name__ == "__main__":
    main()

Perhatikan fungsi exit() mengembalikan False. Di dalam main(), nilai itu dipakai untuk memutuskan break. Di Python, exit sebenarnya juga nama fungsi bawaan untuk keluar dari interpreter. Menimpa nama tersebut bisa membingungkan. Pada program nyata, nama keluar() lebih aman. Kita tetap memakai exit() di modul ini agar sesuai dengan rancangan proyek.

Mengapa memakai if __name__ == "__main__"?

Baris if __name__ == "__main__": memastikan main() hanya dipanggil ketika berkas dijalankan langsung. Jika berkas diimpor sebagai modul, main() tidak otomatis berjalan. Pola ini membuat kode lebih rapi dan aman dipakai ulang. 

# Pyodide menjalankan kode dengan __name__ = "builtins".
# Baris berikut menyamakannya dengan Python biasa.
if __name__ == "builtins":
    __name__ = "__main__"

def sapa():
    print("Halo dari modul Pustaka Mini")

if __name__ == "__main__":
    sapa()

Saat kode di atas dijalankan langsung, Python memberi nilai "__main__" pada variabel __name__ sehingga sapa() dipanggil. Jika berkas diimpor, blok tersebut dilewati.

Pyodide menjalankan kode di namespace khusus dengan nilai __name__ sama dengan "builtins". Karena itu, contoh di modul ini menambahkan pemeriksaan __name__ == "builtins" untuk menyamakan perilaku dengan Python biasa. Pada Python biasa, baris tersebut dilewati karena __name__ sudah bernilai "__main__".

8.7 Pengujian dan Perbaikan

Program yang selesai ditulis belum tentu benar. Kita perlu menguji setiap fitur dengan urutan yang tetap, lalu membandingkan output dengan rancangan. Untuk Pustaka Mini, gunakan skenario berikut.

Skenario pengujian

Langkah Tindakan Hasil yang diharapkan
1 Pilih menu 1 Dua buku awal tampil dengan nomor 1 dan 2.
2 Pilih menu 2, isi data buku baru Buku baru tampil pada daftar berikutnya.
3 Pilih menu 3, ubah buku nomor 1 Data buku nomor 1 berubah, jumlah buku tetap.
4 Pilih menu 4, hapus buku nomor 2, jawab y Buku nomor 2 hilang, jumlah buku berkurang satu.
5 Pilih menu 5 Pesan terima kasih tampil dan program berhenti.

Cara memainkan aplikasi

  1. Buka tab Mini Project, lalu tekan Jalankan & Mainkan.
  2. Program berhenti di Pilih menu (1-5):. Ketik 1 lalu Enter untuk melihat daftar buku.
  3. Pilih 2 untuk menambah buku. Isi judul, penulis, tahun, dan stok dengan data pilihanmu.
  4. Pilih 1 lagi: buku baru harus muncul di daftar.
  5. Coba 3 untuk mengubah dan 4 untuk menghapus buku.
  6. Pilih 5 untuk keluar. Tekan Jalankan & Mainkan lagi untuk memulai sesi baru.

Setiap jawaban yang kamu ketik dipakai program pada langkah berikutnya. Jika ingin memperbaiki kode di tengah sesi, tekan Stop, ubah kode, lalu jalankan lagi dari awal.

Skenario pada tabel di atas juga dipakai tombol Periksa Output untuk menilai hasil secara otomatis.

Masalah umum dan cara memperbaikinya

Gejala Penyebab Perbaikan
Data tidak muncul setelah ditambah Dictionary baru tidak dimasukkan ke daftar_buku. Pastikan memakai append().
Buku yang diubah salah Indeks list tidak dikurangi satu. Gunakan daftar_buku[nomor - 1].
IndexError saat memilih nomor Nomor di luar jumlah data. Periksa batas 1 sampai len(daftar_buku).
Program berulang tanpa berhenti Pilihan keluar tidak memanggil break. Pastikan menu 5 menghentikan while True.
ValueError saat mengisi tahun Nilai yang diketik bukan angka. Bungkus konversi dengan try-except ValueError.

Checklist sebelum menyatakan proyek selesai

  • Semua buku tampil dengan nomor urut yang benar.
  • Buku baru masuk ke daftar dan langsung terlihat pada menu 1.
  • Perubahan hanya mengenai buku yang dipilih.
  • Penghapusan hanya berjalan setelah konfirmasi y.
  • Menu 5 keluar dari program tanpa error.
  • Pilihan selain 1–5 menampilkan pesan dan tidak menghentikan program.
  • Tahun dan stok tersimpan sebagai bilangan bulat.
  • Tidak ada data yang hilang saat program masih berjalan.

Setelah seluruh checklist terpenuhi, mainkan aplikasi lewat tombol Jalankan & Mainkan. Jika aplikasi sudah berjalan sesuai keinginanmu, tekan Periksa Output untuk memverifikasi skenario uji. Setelah output sesuai, kamu dapat membuka halaman penutup dan menyelesaikan seluruh rangkaian modul PYLearn.

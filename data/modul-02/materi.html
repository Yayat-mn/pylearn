2.1 Variabel: Konsep, Aturan Penamaan, dan Penghapusan

Variabel adalah nama yang digunakan untuk merujuk pada sebuah nilai yang disimpan di memori komputer. Dengan variabel, kita dapat menyimpan data, memakainya kembali, dan mengubahnya saat program berjalan. 

nama = "Rani"
umur = 20

print(nama)
print(umur)

Tanda = pada contoh di atas adalah operator penugasan (assignment), bukan tanda sama dengan dalam matematika. Perintah nama = "Rani" berarti nilai "Rani" diberikan kepada variabel nama.

Perbandingan nilai menggunakan tanda == akan dibahas pada Modul 3. Untuk sekarang, ingat bahwa = dipakai untuk mengisi nilai ke variabel.

Python tidak memerlukan deklarasi tipe

Pada Python, kita tidak perlu menuliskan tipe data saat membuat variabel. Tipe data ditentukan secara otomatis dari nilai yang diberikan. Python juga bersifat dinamis, sehingga tipe sebuah variabel dapat berubah jika diberi nilai dengan tipe yang berbeda. 

nilai = 10
print(type(nilai))  # tipe int

nilai = "sepuluh"
print(type(nilai))  # tipe str

Fungsi type() berguna untuk memeriksa tipe data sebuah nilai atau variabel.

Aturan penamaan variabel

  • Nama variabel harus diawali huruf atau garis bawah (_), bukan angka.
  • Nama hanya boleh berisi huruf, angka, dan garis bawah. Spasi serta tanda baca lain tidak diperbolehkan.
  • Python bersifat case-sensitive, sehingga nama dan Nama adalah dua variabel yang berbeda.
  • Nama tidak boleh sama dengan kata kunci Python, misalnya if, else, for, while, def, class, return, True, False, dan None.
  • Gunakan nama yang menjelaskan isi variabel. Penulisan dengan garis bawah, seperti nama_siswa, lebih mudah dibaca daripada ns. 
nama_siswa = "Rani"  # valid
_umur = 20           # valid

# 2nama = "Rani"     # tidak valid: diawali angka
# nama siswa = "Rani"  # tidak valid: mengandung spasi
# class = "A"        # tidak valid: class adalah kata kunci

Menghapus variabel

Variabel dapat dihapus dengan perintah del. Setelah dihapus, variabel tersebut tidak dapat digunakan lagi. Jika kita mencoba mengaksesnya, Python akan menampilkan NameError. 

umur = 20
print(umur)

del umur

# print(umur)  # NameError: name 'umur' is not defined

NameError juga dapat muncul jika kita salah mengetik nama variabel atau memakai variabel yang belum pernah dibuat.

2.2 Tipe Data Number

Python memiliki beberapa tipe data angka. Pada tahap awal, kita perlu mengenal dua tipe yang paling sering digunakan, yaitu integer dan float.

Integer (int)

Integer adalah bilangan bulat, baik positif, negatif, maupun nol. Contohnya 10, -5, dan 0. 

jumlah = 10
suhu = -5
print(jumlah)
print(suhu)
print(type(jumlah))  # int

Float

Float adalah bilangan yang memiliki bagian desimal. Contohnya 3.14, -0.5, dan 160.0. Perhatikan bahwa 10 bertipe integer, sedangkan 10.0 bertipe float. 

berat = 62.5
rasio = -0.25
print(berat)
print(type(berat))  # float

Notasi eksponen

Bilangan yang sangat besar atau sangat kecil dapat ditulis dengan notasi eksponen. Huruf e berarti “kali sepuluh pangkat”. Hasil dari notasi eksponen bertipe float. 

print(1.5e3)   # 1500.0
print(2e-3)    # 0.002
print(1e6)     # 1000000.0

Operator penugasan =

Operator = dipakai untuk memberikan nilai ke variabel. Nilai variabel dapat diganti dengan nilai baru selama program berjalan. 

umur = 20
print(umur)

umur = 21
print(umur)

Pada contoh tersebut, nilai 20 diganti dengan 21. Operator == yang digunakan untuk membandingkan dua nilai akan dipelajari pada Modul 3.

Mengisi beberapa variabel sekaligus

Python memungkinkan beberapa variabel diisi dalam satu baris. Jumlah variabel di kiri harus sama dengan jumlah nilai di kanan. 

nama, umur, tinggi = "Rani", 20, 160.5

print(nama)
print(umur)
print(tinggi)
print(type(tinggi))  # float

Beberapa variabel juga dapat diberi nilai yang sama dalam satu baris. 

x = y = 100
print(x, y)

Jika jumlah nilai tidak sesuai, Python akan menampilkan error. Contohnya a, b = 1, 2, 3 memiliki tiga nilai untuk dua variabel.

2.3 Tipe Data String

String adalah tipe data untuk menyimpan teks, termasuk huruf, angka yang ditulis sebagai teks, spasi, dan simbol. String ditulis dengan tanda petik satu ('...') atau tanda petik ganda ("..."). 

nama = "Rani"
kota = 'Bandung'
kalimat = "Dia berkata, 'Halo!'"

print(nama)
print(kota)
print(kalimat)

Jika teks mengandung tanda petik, gunakan jenis tanda petik yang berbeda atau awali tanda petik di dalam teks dengan garis miring terbalik (\).

String multibaris

String yang terdiri dari beberapa baris dapat dibuat dengan tiga tanda petik, baik tiga tanda petik ganda maupun tiga tanda petik tunggal. 

paragraf = """Python adalah bahasa pemrograman.
Sintaksnya mudah dibaca.
Python banyak digunakan untuk analisis data."""

print(paragraf)

Penggabungan string

Dua string atau lebih dapat digabungkan dengan operator +. Jika ingin ada spasi, tambahkan string berisi spasi di antara keduanya. 

nama_depan = "Rani"
nama_belakang = "Putri"

nama_lengkap = nama_depan + " " + nama_belakang
print(nama_lengkap)  # Rani Putri

Indeks string

Setiap karakter dalam string memiliki posisi yang disebut indeks. Indeks dimulai dari 0. Indeks negatif digunakan untuk menghitung dari belakang, dengan -1 sebagai karakter terakhir. 

teks = "Python"

print(teks[0])   # P
print(teks[1])   # y
print(teks[-1])  # n

Urutan indeks untuk "Python" adalah P=0, y=1, t=2, h=3, o=4, dan n=5.

Pemotongan string

Pemotongan atau slicing mengambil sebagian string dengan pola [mulai:selesai]. Karakter pada posisi selesai tidak ikut diambil. Jika salah satu bagian dikosongkan, Python memakai awal atau akhir string. 

teks = "Python"

print(teks[1:4])  # yth
print(teks[:3])   # Pyt
print(teks[3:])   # hon
print(teks[-3:])  # hon

Pemotongan menghasilkan string baru dan tidak mengubah string asli.

2.4 Tipe Data Boolean

Boolean adalah tipe data yang hanya memiliki dua nilai, yaitu True dan False. Penulisannya harus diawali huruf kapital. Boolean banyak digunakan untuk menyatakan status atau kondisi, misalnya apakah program aktif atau apakah syarat sudah terpenuhi. 

aktif = True
lulus = False

print(aktif)
print(lulus)
print(type(aktif))  # bool

Menuliskan true atau false dengan huruf kecil seluruhnya tidak dikenali sebagai nilai boolean Python. Gunakan True dan False.

Nilai yang dianggap benar atau salah

Saat diubah menjadi boolean, beberapa nilai memiliki arti khusus. Angka 0 dan string kosong "" dianggap False, sedangkan angka selain nol dan string yang berisi teks dianggap True. 

print(bool(0))       # False
print(bool(1))       # True
print(bool(""))      # False
print(bool("0"))     # True
print(bool("Python"))  # True

Perhatikan bahwa "0" adalah string yang berisi satu karakter, bukan angka nol. Karena string tersebut tidak kosong, nilainya dianggap True.

2.5 Konversi Tipe Data

Konversi tipe data dilakukan ketika kita ingin mengubah nilai dari satu tipe ke tipe lain. Python menyediakan beberapa fungsi bawaan untuk keperluan tersebut.

int()

Fungsi int() mengubah nilai menjadi integer. Jika nilai berupa float, bagian desimalnya dipotong. Jika nilai berupa string, isi string harus berupa bilangan bulat yang valid. 

print(int("25"))   # 25
print(int(3.9))    # 3
print(int(-2.8))   # -2

# int("abc")       # ValueError

float()

Fungsi float() mengubah nilai menjadi float. Fungsi ini dapat menerima angka atau string yang berisi bilangan desimal. 

print(float("3.14"))  # 3.14
print(float(10))      # 10.0

str()

Fungsi str() mengubah nilai menjadi string. Fungsi ini sering dipakai saat kita ingin menggabungkan angka dengan teks memakai operator +. 

umur = 20
print("Umur: " + str(umur))

print(str(42))    # "42"
print(str(3.14))  # "3.14"

bool()

Fungsi bool() mengubah nilai menjadi boolean. Angka nol dan string kosong menjadi False; nilai lain umumnya menjadi True. 

print(bool(0))     # False
print(bool(1))     # True
print(bool(""))    # False
print(bool("0"))   # True

chr()

Fungsi chr() mengubah kode bilangan bulat menjadi karakter Unicode. Contohnya kode 65 mewakili huruf A. 

print(chr(65))  # A
print(chr(97))  # a

bin(), hex(), dan oct()

Fungsi-fungsi ini mengubah bilangan bulat menjadi string representasi biner, heksadesimal, dan oktal. Hasilnya berupa string yang diawali 0b untuk biner, 0x untuk heksadesimal, dan 0o untuk oktal. 

print(bin(10))   # 0b1010
print(hex(255))  # 0xff
print(oct(8))    # 0o10

Jika konversi tidak dapat dilakukan, Python dapat menampilkan ValueError, misalnya pada int("abc"). Pastikan isi string sesuai dengan tipe tujuan.

Konversi tidak mengubah variabel asli

Fungsi konversi menghasilkan nilai baru. Variabel asli tetap memiliki tipe dan nilai sebelumnya kecuali kita memberikan hasil konversi kembali ke variabel tersebut. 

angka = "10"
hasil = int(angka)

print(type(angka))  # str
print(type(hasil))  # int

Contoh gabungan

nama = "Rani"
umur = 20
tinggi = 160.5
aktif = True

print("Nama:", nama)
print("Umur:", umur)
print("Tinggi:", tinggi)
print("Aktif:", aktif)

Kode tersebut menggunakan variabel dari beberapa tipe data. Pola serupa akan kamu gunakan pada latihan Modul 2.

Rangkuman

  • Variabel adalah nama yang merujuk pada nilai. Python tidak memerlukan deklarasi tipe, dan tipe variabel dapat berubah.
  • Nama variabel harus diawali huruf atau garis bawah, tidak boleh mengandung spasi, bersifat case-sensitive, dan tidak boleh memakai kata kunci Python.
  • Variabel dapat dihapus dengan del. Mengakses variabel yang sudah dihapus atau belum dibuat menimbulkan NameError.
  • Tipe number yang umum adalah int untuk bilangan bulat dan float untuk bilangan desimal. Notasi eksponen seperti 1.5e3 menghasilkan float.
  • String ditulis dengan tanda petik, dapat berupa string multibaris, dapat digabungkan dengan +, serta dapat diakses dengan indeks dan pemotongan.
  • Boolean hanya bernilai True atau False. Angka nol dan string kosong dianggap False.
  • Fungsi konversi meliputi int(), float(), str(), bool(), chr(), bin(), hex(), dan oct().

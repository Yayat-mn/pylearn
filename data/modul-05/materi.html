5.1 Konsep Perulangan dan Counted vs Uncounted Loop

Perulangan atau looping adalah cara menjalankan blok perintah secara berulang. Dengan perulangan, kita tidak perlu menulis perintah yang sama berkali-kali. Cukup tulis satu blok, lalu tentukan berapa kali atau sampai kapan blok itu diulang.

Sebagai gambaran, tiga perintah print() berikut dapat digantikan dengan satu perulangan. 

print("Halo")
print("Halo")
print("Halo")

Bentuk perulangannya adalah sebagai berikut.

for i in range(3):
    print("Halo")

Keduanya menampilkan kata Halo sebanyak tiga kali. Perulangan membuat kode lebih singkat dan lebih mudah diubah.

Counted loop dan uncounted loop

Python memiliki dua bentuk perulangan yang umum digunakan, yaitu for dan while.

  • Counted loop adalah perulangan yang jumlah iterasinya dapat diketahui sejak awal. Di Python, bentuk ini biasanya menggunakan for, misalnya for i in range(5).
  • Uncounted loop adalah perulangan yang berhenti berdasarkan kondisi, sehingga jumlah iterasinya belum tentu diketahui sejak awal. Bentuk ini menggunakan while.

Perulangan for cocok untuk mengulang sejumlah data atau menelusuri isi list. Perulangan while cocok ketika program harus terus berjalan sampai suatu kondisi tidak lagi terpenuhi.

Pada editor PYLearn, nilai variabel diisi langsung di dalam kode karena fungsi input() belum didukung. Kamu tetap dapat mencoba perulangan dengan mengubah nilai variabel pada kode.

5.2 Perulangan for dengan range()

Perulangan for sering dipakai bersama fungsi range() untuk mengulang sejumlah kali. Bentuk dasarnya adalah for variabel in range(jumlah):. 

for i in range(5):
    print(i)

Kode tersebut menampilkan angka 0 sampai 4, bukan 0 sampai 5. Fungsi range(5) menghasilkan 0, 1, 2, 3, dan 4. Nilai batas akhir tidak ikut dihasilkan.

Menentukan nilai awal dan akhir

range() juga dapat menerima nilai awal dan nilai akhir. Bentuk range(1, 6) menghasilkan angka 1 sampai 5. 

for i in range(1, 6):
    print("Angka:", i)

Nilai awal ikut dihasilkan, sedangkan nilai akhir tidak ikut dihasilkan. Karena itu, range(1, 6) berhenti sebelum angka 6.

Mengubah angka menjadi string pada output

Operator + dapat menyambung dua string, tetapi tidak dapat menyambung string dengan angka. Jika ingin menggabungkan teks dan angka, ubah angka menjadi string dengan str(). 

for i in range(1, 4):
    print("Putaran ke-" + str(i))

Fungsi str(i) mengubah nilai angka pada variabel i menjadi string. Tanpa str(), Python akan menampilkan TypeError karena string dan integer tidak dapat digabung dengan operator +.

Mengatur langkah perulangan

Argumen ketiga pada range() menentukan langkah atau step. Contoh range(1, 10, 2) menghasilkan 1, 3, 5, 7, dan 9. 

for i in range(1, 10, 2):
    print(i)

Langkah juga dapat bernilai negatif untuk menghitung mundur. 

for i in range(3, 0, -1):
    print(i)

Perulangan tersebut menampilkan 3, 2, dan 1. Jumlah perulangan dapat pula disimpan dalam variabel, seperti contoh berikut. 

jumlah = 4

for i in range(jumlah):
    print("Data ke-" + str(i + 1))

Kode tersebut menampilkan Data ke-1 sampai Data ke-4. Perulangan for dengan range() termasuk counted loop karena jumlah iterasinya sudah ditentukan.

5.3 Perulangan for pada List

Selain dengan range(), perulangan for dapat digunakan untuk menelusuri setiap elemen dalam list. List adalah kumpulan nilai yang ditulis di antara tanda kurung siku. 

buah = ["apel", "jeruk", "mangga"]

for item in buah:
    print(item)

Pada setiap iterasi, variabel item berisi satu elemen dari list. Program menampilkan apel, lalu jeruk, lalu mangga. Perulangan berhenti otomatis setelah semua elemen selesai diproses.

Nama variabel setelah for boleh berbeda, misalnya buah_terpilih. Yang penting, variabel tersebut menerima nilai setiap elemen list. 

buah = ["apel", "jeruk", "mangga"]

for buah_terpilih in buah:
    print("Buah: " + buah_terpilih)

Perulangan juga dapat digunakan untuk mengolah angka pada list. Contoh berikut menjumlahkan seluruh harga. 

harga = [10000, 25000, 15000]
total = 0

for h in harga:
    total += h

print("Total belanja: " + str(total))

Variabel total diisi 0 sebelum perulangan. Setiap harga ditambahkan ke total sehingga hasil akhirnya adalah 50000. Fungsi str(total) digunakan agar angka dapat digabung dengan teks pada print().

5.4 Perulangan while dan Kondisi Berhenti

Perulangan while akan menjalankan blok perintah selama kondisinya bernilai True. Ketika kondisi menjadi False, perulangan berhenti. 

hitung = 1

while hitung <= 5:
    print("Hitung:", hitung)
    hitung += 1

Ada tiga bagian penting pada perulangan tersebut. Pertama, variabel hitung diberi nilai awal 1. Kedua, kondisi hitung <= 5 diperiksa sebelum setiap iterasi. Ketiga, hitung += 1 memperbarui nilai agar suatu saat kondisi menjadi False.

Jika variabel penghitung tidak diperbarui, kondisi dapat terus bernilai True dan perulangan tidak pernah berhenti. Perulangan seperti itu disebut infinite loop. Di PYLearn, program yang berjalan lebih dari 5 detik akan dihentikan otomatis, dan kamu juga dapat menekan tombol Stop.

Hitungan mundur

hitung = 3

while hitung > 0:
    print(hitung)
    hitung -= 1

print("Selesai!")

Kode tersebut menampilkan 3, 2, 1, lalu Selesai!. Perulangan berhenti ketika hitung bernilai 0 karena kondisi hitung > 0 tidak lagi terpenuhi.

Perulangan berdasarkan kondisi

Perulangan while juga dapat digunakan ketika jumlah iterasi tidak ditentukan sejak awal. Contoh berikut menambah saldo sampai mencapai target. 

saldo = 0
target = 100000

while saldo < target:
    saldo += 30000
    print("Saldo:", saldo)

Saldo bertambah 30000 setiap iterasi. Perulangan berhenti setelah saldo mencapai 120000 karena kondisi saldo < target sudah bernilai False. Nilai akhir dapat melewati target karena pemeriksaan dilakukan sebelum menambah saldo.

Hindari menulis while True: tanpa perintah break di dalamnya. Pola tersebut akan membuat perulangan berjalan terus-menerus.

5.5 Perintah break dan Penerapannya

Perintah break digunakan untuk menghentikan perulangan lebih awal. Setelah break dijalankan, program keluar dari perulangan dan melanjutkan perintah setelah blok perulangan. 

for i in range(1, 6):
    if i == 3:
        break
    print(i)

Perulangan seharusnya berjalan untuk angka 1 sampai 5. Namun, ketika i bernilai 3, perintah break dijalankan sehingga hanya angka 1 dan 2 yang ditampilkan.

break juga sering digunakan bersama while True agar perulangan memiliki jalan keluar. 

hitung = 1

while True:
    print("Putaran ke-" + str(hitung))

    if hitung == 3:
        break

    hitung += 1

Perulangan menampilkan putaran ke-1, ke-2, dan ke-3. Setelah hitung bernilai 3, perintah break menghentikan perulangan.

Mencari data dalam list

buah = ["apel", "jeruk", "mangga"]
dicari = "jeruk"

for item in buah:
    if item == dicari:
        print("Ditemukan: " + item)
        break

print("Pencarian selesai")

Program memeriksa list satu per satu. Ketika menemukan jeruk, program menampilkan hasil lalu menghentikan perulangan. Perintah print("Pencarian selesai") tetap dijalankan karena berada di luar perulangan.

Membatasi total belanja

total = 0
harga = [10000, 25000, 15000, 40000]

for h in harga:
    total += h

    if total > 50000:
        print("Batas belanja terlampaui")
        break

print("Total:", total)

Total dihitung secara bertahap. Setelah harga keempat ditambahkan, total menjadi 90000 sehingga melewati batas 50000. Perintah break menghentikan perulangan dan program menampilkan total akhir.

Rangkuman

  • Perulangan digunakan untuk menjalankan blok perintah secara berulang. Python memiliki for dan while.
  • for adalah counted loop karena jumlah iterasinya dapat diketahui, misalnya melalui range() atau jumlah elemen list.
  • range(5) menghasilkan 0 sampai 4, sedangkan range(1, 6) menghasilkan 1 sampai 5.
  • str() digunakan untuk mengubah angka menjadi string ketika angka akan digabung dengan teks.
  • while adalah uncounted loop yang berjalan selama kondisinya bernilai True. Variabel pada kondisi harus diperbarui agar perulangan berhenti.
  • break menghentikan perulangan lebih awal, baik pada for maupun while.
